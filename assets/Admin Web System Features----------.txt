Admin Web System Features-------------

Admin Login and Dashboard Overview

Resort Booking Management (view, approve, reject, and modify reservations)

Calendar Schedule Monitoring (view all reservations using a centralized calendar)

Activity and Facility Management (ADV, Gym, Billiards, Pool, Basketball Court, Videoke, Kids Playground)

Bundle and Discount Management (create packages and promotional offers)

Food Menu Management (add, edit, or remove food offerings)

Customer Account Management (view and manage registered users)

Payment Verification Management (verify GCash reservation payments)

Notification and Reminder Management (send alerts for booking confirmation and late arrivals)

Reservation Monitoring and Reports (view booking records and summaries)

Client / User Application Features------------

Account Registration and Login

Password Recovery via Email Code (PHPMailer)

User Profile Management

Resort Booking Reservation

Activity-Based Booking (book specific activities such as basketball, swimming, billiards, gym, etc.)

Package and Bundle Booking

Food Ordering Add-ons

Booking Calendar Availability Checking

GCash QR Reservation Fee Payment

Booking Status Monitoring (pending, approved, rejected)

Booking History and Records

Automated Booking Reminder Notifications

Installable Progressive Web Application (PWA)
